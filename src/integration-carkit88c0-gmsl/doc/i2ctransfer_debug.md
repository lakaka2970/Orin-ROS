# i2ctransfer 命令分析（GMSL 调试）

本文档整理了在调试过程中执行的所有 `i2ctransfer -y -f 2 w2@` 读取命令，按目标设备地址分组，并给出寄存器的常见含义。

> 注：`w2@` 表示写两个字节的寄存器地址（16 位），然后读取指定长度的数据。例如 `w2@0x42 0x03 0x8E r1` 表示向地址 `0x42` 的设备写入寄存器地址 `0x038E`，然后读取 1 个字节。

---

## 1. 设备地址 `0x42`（MAX96717 串行器）

| 寄存器地址（高字节 低字节） | 读取值（示例） | 常见含义 | 备注 |
|------------------------------|---------------|----------|------|
| `0x00 0x13` | `0xEA` 等 | **链路状态寄存器**：bit3 表示 GMSL 链路锁定 | 锁定状态正常时 bit3=1 |
| `0x00 0x02` | `0x43` | **视频传输使能**：`0x43` 表示 `VID_TX_EN_Z` 已使能 | 应为 `0x43` 才能转发数据 |
| `0x03 0x13` | `0x40` | **双倍模式控制**：`0x40` 表示启用 12-bit 双倍模式 | 与数据位宽有关 |
| `0x03 0x1E` | `0x38` | **软件 BPP 覆盖**：`0x38` 表示软件覆盖启用 | 通常应为 `0x38` |
| `0x00 0x5B` | `0x00` | **管道选择**：`0x00` 表示 Pipe Z | 常用于选择数据管道 |
| `0x01 0x70` | `0x0B` | **SPI/视频控制**：`0x0B` 表示允许视频传输 | 需检查是否与配置一致 |
| `0x03 0x30` | `0x00` 或 `0x08` | **MIPI 端口配置**：bit6 控制时钟模式 | 0x00=连续时钟，0x08=复位 |
| `0x03 0x8D` | `0x42` 等 | **PHY1 数据包计数**：表示从 MIPI 收到的数据包数 | 递增说明串行器收到雷达数据 |
| `0x03 0x8E` | `0x00` | **CSI 数据包计数**：表示转发到 GMSL 的数据包数 | **关键**：若始终为 0，则数据未转发 |
| `0x03 0x90` | `0xA5` 等 | **PHY 时钟计数**：MIPI 时钟活动计数 | 递增表示时钟正常 |
| `0x01 0x12` | `0x0A` | **视频发送器状态**（VIDEO_TX2） | 状态值需参考手册 |
| `0x03 0x3C` | `0x00` | **PHY1 高速错误计数** | 非零表示有错误 |
| `0x03 0x3E` | `0x00` | **PHY2 高速错误计数** | 同上 |
| `0x02 0x4F` | `0x01` | **VTX1 状态** | 视频发送器配置状态 |
| `0x03 0x43` | `0x00` | **MIPI_RX19** | 状态寄存器 |
| `0x03 0x44` | `0x00` | **MIPI_RX20** | 状态寄存器 |
| `0x00 0x1F` | `0x00` | **中断状态寄存器** | 0 表示无中断 |

## 2. 设备地址 `0x48`（MAX9296 解串器）

| 寄存器地址（高字节 低字节） | 读取值（示例） | 常见含义 | 备注 |
|------------------------------|---------------|----------|------|
| `0x00 0x13` | `0xEA` | **链路状态寄存器**：bit3=1 表示链路锁定 | 当前为锁定状态 |
| `0x00 0x00` | `0x90` | **芯片 ID**：固定值，表示 MAX9296 | 通信正常 |
| `0x00 0x01` | `0x02` | **芯片版本/保留** | 可能为版本号 |
| `0x00 0x02` | `0xF3` | **保留或状态** | 需手册确认 |
| `0x03 0x13` | `0x02` | **CSI 输出使能**：`0x02` 表示使能 | 输出已开启 |
| `0x03 0x20` | `0x2C` | **CSI 速率控制**：`0x2C` = 1200 Mbps | 可尝试其他值（如 0x1C） |
| `0x04 0x0B` | `0x07` | **管道 X 映射使能**：三路映射使能 | 正常 |
| `0x04 0x0D` | `0x2C` | **管道 X 源映射**：DT=0x2C (RAW12) | 与格式匹配 |
| `0x04 0x0E` | `0x2C` | **管道 X 目标映射**：DT=0x2C | 同上 |
| `0x03 0x30` | `0x04` | **CSI 端口配置**：`0x04` = 1x4 模式 | 正常 |
| `0x03 0x33` | `0x4E` 或 `0xE4` | **Lane 映射**：决定数据线到 PHY 的映射 | 尝试改为 `0xE4` 以适配标准 |
| `0x03 0x34` | `0xE4` | **PHY1 极性配置** | 可能需清零 |
| `0x03 0x35` | `0x00` | **PHY2 极性配置** | 正常 |
| `0x01 0x1A` | `?` | 状态寄存器 | 未明确 |
| `0x01 0x08` | `?` | 状态寄存器 | 未明确 |
| `0x01 0x2C` | `?` | 状态寄存器 | 未明确 |
| `0x01 0x3E` | `?` | 状态寄存器 | 未明确 |
| `0x0B 0x15` | `?` | 可能为 CSI 错误计数 | 需手册 |
| `0x0C 0x15` | `?` | 可能为 CSI 错误计数 | 需手册 |
| `0x01 0x12` | `?` | 状态寄存器 | 未明确 |
| `0x01 0x36` | `?` | 状态寄存器 | 未明确 |
| `0x01 0x00` | `?` | 状态寄存器 | 未明确 |
| `0x01 0x24` | `?` | 状态寄存器 | 未明确 |
| `0x00 0x19` | `?` | 控制/状态寄存器 | 未明确 |
| `0x00 0x22` | `?` | 控制/状态寄存器 | 未明确 |
| `0x00 0x23` | `?` | 控制/状态寄存器 | 未明确 |
| `0x00 0x25` | `?` | 控制/状态寄存器 | 未明确 |
| `0x00 0x1D` | `?` | 控制/状态寄存器 | 未明确 |
| `0x00 0x1B` | `?` | 控制/状态寄存器 | 未明确 |
| `0x00 0x32` | `?` | 控制/状态寄存器 | 未明确 |
| `0x03 0x12` | `?` | 可能为 CSI 错误状态 | 需手册 |
